Esquisse works like SketchUp: you draw lines and shapes, faces appear by themselves, you push
and pull them, and you type exact dimensions on the keyboard. It reads and writes `.skp` files
from every SketchUp version, 3 to 2026, runs Ruby extensions written for SketchUp, and works
without SketchUp or any Trimble file installed. It is released under the MIT licence.

The user interface is in French for now; the screenshots in this repository show it as it is.

## In numbers

- **`.skp` files**: of 1,967 real files saved by SketchUp 3 to 2026 and collected from public
  repositories, 1,966 are read exactly as SketchUp's SDK reads them, object class by object
  class.
- **Application features**: 332 of 332 (commands, tools, file formats, panels, Model Info,
  Preferences), excluding Trimble's online services.
- **Ruby API**: all 1,855 methods of the SketchUp 2026 API exist; the official API test suite
  (TestUp) passes 2,563 of 3,020 tests.
- **Tests**: 1,366 automated tests.

## What you can do

### Draw and model

- Line, freehand, arcs (two-point, three-point, centre, pie), rectangle, rotated rectangle,
  circle, polygon.
- "Sticky" geometry: a closed planar outline becomes a face, a line drawn across a face splits
  it, a rectangle inside a face makes a hole.
- Push/Pull, Follow Me, Offset, Move and copy (arrays), Rotate, Scale, Flip, Eraser (hide,
  soften).
- Inference on endpoints, midpoints, edges, faces and axes; arrow keys lock a direction, Shift
  locks the current inference.
- Measurements box: lengths, angles, segment counts and arrays are typed on the keyboard, in
  the model's units.
- Tape Measure and Protractor (guides), Intersect Faces, Soften Edges, Weld Edges.
- Solid tools: Union, Subtract, Intersect, Trim, Split, Outer Shell.
- Sandbox: terrain from contours or from scratch, Smoove, Stamp, Drape, Add Detail, Flip Edge.
- 3D Text, Dimensions, leader Text; attached dimensions and texts follow what they are attached
  to.
- Section planes, with section fill.

### Organise

- Groups and components: shared definitions, make unique, explode, glue to a face, cut
  opening, always face the camera.
- Outliner, Tags (folders, colours, dashes) and Entity Info panels.
- Classifier and IFC classifications.

### Materials, styles and presentation

- Materials: colour, texture, opacity, colorize, PBR settings; position, project and make
  unique a texture.
- Styles: edges (sketchy, by axis, by material, profiles, endpoints), faces, background, sky
  and ground, watermarks, modelling settings; style mixing.
- Shadows (sun, date, time, geo-location), fog, environments (HDR panoramas as background and
  for reflections), ambient occlusion, overlays, model grid.
- Cameras: orbit, pan, zoom, field of view, perspective, parallel projection, two-point
  perspective, position camera, walk, Match Photo.
- Scenes, transitions and animation.

### Files

- `.skp`: native open and save for SketchUp 3 to 2026, save as an older version, lossless
  round trip (textures, styles, scenes, attributes, dimensions).
- Import: 3DS, COLLADA, DEM, DWG and DXF, glTF and GLB, IFC, KMZ, STL, TRB, USD and USDZ;
  BMP, JPEG, PNG, PSD, TGA, TIFF and PDF images, as an image, a texture or a matched photo.
- 3D export: 3DS, COLLADA, DWG and DXF, FBX, IFC, KMZ, OBJ, STL, VRML, XSI, glTF and GLB,
  USDZ.
- 2D export: PNG, JPEG, BMP, TIFF, vector PDF, EPS, DWG and DXF (hidden lines), section slice;
  animation as MP4, WebM, AVI or an image sequence; printing.
- Native `.esq` format, in JSON.

### Bundled content

300 materials, 111 styles, 18 environments, 21 templates, 12 components, 12 hatch patterns and
2 IFC classifications, all generated by Esquisse and under the MIT licence.

### Ruby extensions

- Embedded Ruby 3.2 (the same version as SketchUp 2026) and SketchUp's whole API: geometry,
  entities, tools, observers, `UI::HtmlDialog`, menus and toolbars.
- Ruby Console, Extension Manager, `Plugins` folder, `.rbz` installation.

### Settings

Preferences (shortcuts, default template, auto-save…), Model Info (units, geo-location,
statistics…), panel trays, toolbars, command search.

## What is missing

- Trimble's online services (3D Warehouse, Extension Warehouse, Trimble Connect, AI assistant
  and AI render, pre-design, licensing, updates): out of scope.
- LayOut and Style Builder, which are separate applications.
- The interface is French only, and Esquisse runs on Windows 10 and 11 (64-bit) only.
- Encrypted extensions (`.rbe`, `.rbs`) do not load, and two menu entries are still greyed
  out: the Dynamic Components Interact tool and the location pin.
- 457 TestUp tests do not pass yet, and 1 real `.skp` file out of 1,967 still differs from the
  SDK.
- Video export needs ffmpeg, which is not bundled.
- There is no release yet: Esquisse is built from source.

## Build and run

Requirements: Windows 10 or 11 (64-bit), stable [Rust](https://rustup.rs) with the MSVC
toolchain (Visual Studio Build Tools, C++), and for the Ruby API the
[RubyInstaller](https://rubyinstaller.org) 3.2 x64 (`.7z` archive, no installation needed).

```powershell
git clone https://github.com/ponthieutheo/esquisse
cd esquisse
cargo build --release
powershell -File tools\ruby-dev.ps1 -Ruby C:\path\to\rubyinstaller-3.2.11-1-x64 -Release
target\release\esquisse.exe
```

Without Ruby, Esquisse works but without extensions. A self-contained folder, ready to copy to
another PC, is made with `powershell -File tools\package.ps1 -Ruby <RubyInstaller folder>`
(output in `target\paquet\Esquisse`).

Tests: `cargo test --workspace`. Ruby tests are skipped without a Ruby runtime; with
`ESQ_REQUIRE_RUBY=1`, a missing runtime makes them fail.
