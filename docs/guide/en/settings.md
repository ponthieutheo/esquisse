# Settings

[Guide](../../../README.en.md#documentation) · [Français](../reglages.md)

## Preferences

![Window › Preferences, General page](../../media/preferences.jpg)

**Fenêtre › Préférences** (Window › Preferences) sets up the application: accessibility (axis and
inference colours), applications (image editor), compatibility (selection, wheel), drawing
(click-drag, crosshairs), workspace, file locations, general (backup copy, auto-save, model
checks), graphics (anti-aliasing), default template and keyboard shortcuts. Shortcuts can be
assigned, imported, exported and reset; preferences can be exported and imported.

## Model Info

![Window › Model Info, Units page](../../media/infos-modele.jpg)

**Fenêtre › Infos sur le modèle** (Window › Model Info) sets up the open model: animation,
classifications, components (fade the rest of the model while editing), credits, dimensions,
file, geo-location, rendering, statistics (purge, fix), text and units (format, precision,
length and angle snapping). These settings are saved in the `.skp`.

## Workspace

- **Fenêtre › Gérer les palettes** (Window › Manage Trays) creates, renames and arranges panel
  trays.
- **Affichage › Barres d'outils** (View › Toolbars) shows or customises toolbars.
- **Aide › Rechercher dans Esquisse** (Help › Search, Shift+S) finds a command by name and runs
  it.
- The user's preferences, trays and extensions live in `%APPDATA%\Esquisse`.
