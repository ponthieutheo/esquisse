## Fenêtre d'accueil

![Fenêtre d'accueil : modèles types et fichiers récents](../media/accueil.jpg)

Au démarrage, la fenêtre d'accueil propose de créer un modèle à partir d'un modèle type
(Simple, Visualisation, Architecture, Vue en plan, Urbanisme, Paysage, Menuiserie, Intérieurs,
Impression 3D, chacun en unités métriques ou impériales), d'ouvrir un fichier ou de reprendre
un fichier récent. Le cœur marque le modèle type utilisé par **Fichier › Nouveau**. La fenêtre
peut être désactivée dans **Fenêtre › Préférences › Général**.

## L'interface

![Esquisse avec une maison modélisée, la barre d'outils et le panneau Matières](../media/apercu.jpg)

- **Menus** : Fichier, Édition, Affichage, Caméra, Dessiner, Outils, Fenêtre, Extensions,
  Aide, avec les mêmes commandes et les mêmes raccourcis que SketchUp.
- **Barre d'outils** : sélection, dessin, modification, construction et caméra. D'autres
  barres s'affichent depuis **Affichage › Barres d'outils**.
- **Palette de panneaux**, à droite : Infos sur l'entité, Matières, Composants, Styles,
  Étiquettes, Ombres, Scènes, Adoucir les arêtes, Structure, Brouillard, Environnements,
  Incrustations. **Fenêtre › Gérer les palettes** en crée d'autres.
- **Barre d'état**, en bas : ce que l'outil actif attend et ses touches de modification ; à
  droite, la boîte de mesures.

## Naviguer

| Action | Souris ou clavier |
|---|---|
| Orbite | bouton du milieu, ou `O` |
| Panoramique | Maj + bouton du milieu, ou `H` |
| Zoom | molette, ou `Z` |
| Zoom étendu | `Maj+Z` |
| Vues standard | **Caméra › Vues standard** |

La molette zoome vers le point sous le curseur. **Caméra** propose aussi la perspective, la
projection parallèle et la perspective à deux points.

## Ouvrir et enregistrer

**Fichier › Ouvrir** lit les `.skp` de toutes les versions de SketchUp et le format natif
d'Esquisse, `.esq`. **Enregistrer** écrit le `.skp` dans la version actuelle (2026) ;
**Enregistrer sous** propose aussi les versions antérieures. Le détail est dans
[Fichiers](fichiers.md).
